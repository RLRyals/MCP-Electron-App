Component Version Matrix

Each row is a published release: the app version, and the Docker image versions that release's docker-compose.yml pins. Generated at publish time by reading package.json and docker-compose.yml as they existed at each release tag, so this always reflects what actually shipped — not a hand-maintained list.

MCP Writing Servers is built from source, cloned from RLRyals/MCP-Writing-Servers on its default branch at install/update time — it is tracked by branch, not pinned to a tag per app release, so it has no single version number to show in this table. fictionlab-workflow and fictionlab-kanban are optional plugins installed independently from the in-app Plugins screen; see each plugin's own GitHub Releases page for its version history.

The component matrix will appear here once the publish workflow has run at least once.

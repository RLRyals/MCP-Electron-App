Install Guides

Download the latest installer for your platform from GitHub Releases. FictionLab handles the rest — Docker containers, database setup, and MCP client configuration — through its setup wizard. No terminal commands required.

Windows

  1. Download FictionLab-Setup.exe (Windows 10/11, 64-bit).
  2. Double-click the installer.
  3. Follow the installation wizard (choose an install folder if you like).
  4. Click "Install" and wait for it to finish.
  5. Launch FictionLab from the Start Menu or the desktop shortcut.

Windows may show an "Unknown Publisher" warning — the installer isn't code-signed yet. Click "More info" → "Run anyway" to continue.

macOS

  1. Download FictionLab.dmg (macOS 10.15+, Intel and Apple Silicon).
  2. Open the downloaded DMG file.
  3. Drag the FictionLab icon to your Applications folder.
  4. Open FictionLab from Applications.

macOS may say "App can't be opened" because the app isn't notarized yet. Right-click the app → "Open" → "Open" to bypass Gatekeeper the first time.

Linux

  1. Download FictionLab.AppImage or fictionlab.deb (Ubuntu 20.04+, Debian, other distros).
  2. AppImage: make it executable and run it: 
    chmod +x FictionLab.AppImage
./FictionLab.AppImage
  3. .deb: install with: 
    sudo dpkg -i fictionlab.deb
  4. Launch FictionLab from your applications menu.

What the setup wizard does for you

After launch, FictionLab's setup wizard automatically:

  • Detects (or helps you install) Docker
  • Provisions and starts the PostgreSQL database, with a securely generated password
  • Starts the MCP Writing Servers and the local MCP Connector
  • Connects your AI client of choice (TypingMind, recommended for beginners, or Claude Desktop)

See What Gets Installed for the full component list.

Verifying a download

Every release includes a checksums-*.txt file alongside the installers. Compare the SHA256 hash of what you downloaded against the matching line before installing.

Cross-platform tester checklist

A structured TESTING.md checklist (install, first-run wizard, Docker detection, database init, connector health check) is tracked as part of the cross-platform testing effort for FictionLab and will be linked here once it lands in the repo. In the meantime, the install steps above cover the same ground for manual testing.

About this site

This site is rebuilt automatically every time a release is published on the FictionLab (MCP-Electron-App) repo via .github/workflows/pages.yml. Release notes and the component matrix are pulled live from the GitHub Releases API and the repository at each tagged release; nothing here is hand-maintained per release.

FictionLab is an installer/management app for a self-hosted AI writing workspace. Source: github.com/RLRyals/MCP-Electron-App.
